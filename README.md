# RESEARCH

Installable neon-pink 20-task organizer.

## GitHub Pages

Upload the seven files in this ZIP individually to the **root** of the branch used by GitHub Pages. Do not upload the ZIP itself. Do not create an `icons` folder: all icon references point to files at the root.

Set GitHub Pages to **Deploy from a branch**, choose the branch containing `index.html`, and select **/(root)**.

## Features

Add tasks, complete them with checkboxes, and drag tasks by the dotted handle. Tasks are saved in this browser on this device.


This variant uses yellow neon styling, a open book icon, and 40 entries.
